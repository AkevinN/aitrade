### 1.1 任务系统

#### TaskStatus (枚举)
```python
class TaskStatus(str, Enum):
    PENDING = "pending"       # 已创建，等待执行
    RUNNING = "running"       # 执行中
    COMPLETED = "completed"   # 已完成
    FAILED = "failed"         # 失败
```

#### TaskType (枚举)
```python
class TaskType(str, Enum):
    DATA_DOWNLOAD = "data_download"     # Tushare 数据下载
    DATA_IMPORT = "data_import"         # CSV 导入
    DATA_AGGREGATE = "data_aggregate"   # 周期聚合
    DATASET_CREATE = "dataset_create"   # 数据集创建
    MODEL_TRAIN = "model_train"         # Alpha 模型训练
    SIGNAL_GENERATE = "signal_generate" # 信号生成
    BACKTEST_RUN = "backtest_run"       # 策略回测
    CNN_TRAIN = "cnn_train"             # CNN 训练
```

#### TaskModel
```python
class TaskModel(BaseModel):
    task_id: str                    # 8 位 hex 唯一 ID
    type: TaskType                  # 任务类型
    title: str                      # 显示标题
    entity_type: str                # 关联实体类型 ("data" / "cnn_model" / ...)
    entity_name: str                # 关联实体名称
    status: TaskStatus              # 当前状态
    progress: float                 # 0.0 ~ 100.0
    message: str                    # 最新进度消息
    result: dict | None             # 完成时的结果数据
    created_at: datetime            # 创建时间
    updated_at: datetime            # 最后更新时间
```

#### ModelTrainRequest
```python
class ModelTrainRequest(BaseModel):
    name: str                       # 模型名称
    dataset: str                    # 数据集名称
    model_type: str = "lgb"         # lgb | mlp | lasso
    params: dict = {}               # 模型超参
```

**模型超参详述**:

| model_type | 参数 | 默认值 | 说明 |
|-----------|------|--------|------|
| lgb | num_boost_round | 200 | 迭代轮数 |
| lgb | learning_rate | 0.05 | 学习率 |
| lgb | num_leaves | 64 | 叶子数 |
| mlp | hidden_sizes | (256,128) | 隐藏层尺寸 |
| mlp | epochs | 50 | 训练轮数 |
| mlp | lr | 0.001 | 学习率 |
| lasso | alpha | 0.01 | 正则化系数 |

## 四、CNN 张量与存储结构

### 训练张量维度

| 维度 | 符号 | 说明 |
|------|------|------|
| N | batch | 样本数 |
| C | channels | 6 个特征通道 |
| T | time_steps | 回看窗口 (默认 30) |
| S | width | 组内最大证券数 |
| G | groups | 分组数 |

**特征通道 (C=6)**:
1. `pct_change` — 收益率
2. `volume_ratio` — 成交量比 (vs 5日均量)
3. `amplitude` — 振幅
4. `ma5_diff` — 对 MA5 偏离
5. `ma20_diff` — 对 MA20 偏离
6. `high_low_ratio` — 高低价比

## 五、数据文件格式

### Parquet 文件 — K 线数据

| 列名 | 类型 | 说明 |
|------|------|------|
| `datetime` | Datetime | 时间戳 |
| `symbol` | String | 证券代码 |
| `exchange` | String | 交易所 |
| `vt_symbol` | String | 完整标识 (symbol.exchange) |
| `open` | Float64 | 开盘价 |
| `high` | Float64 | 最高价 |
| `low` | Float64 | 最低价 |
| `close` | Float64 | 收盘价 |
| `volume` | Float64 | 成交量 |
| `turnover` | Float64 | 成交额 |
| `open_interest` | Float64 | 持仓量 |
