## 〇、一句话目标

在不破坏现有 CNN 链路的前提下，让 aitrade 支撑**免训练规则型策略**（ETF 动量轮动、可转债双低轮动、小市值轮动）的"数据接入 → 信号生成 → 可信回测 → 半自动调仓提醒 → 组合级风控"端到端闭环，并把"信号源"重构为系统的一等公民抽象。

**安全边界不变**：v1 仍然只产出决策与提醒、不自动下单（延续 Property 7：API 路由不 import 任何券商网关）。

## 一、探索（现状勘察结论）

> 以下事实由 4 个勘察 agent 于 2026-06-11 逐行核实，含确切证据位置。

### 1.1 总体判断：复用度极高，架构收敛点是信号契约

全系统已经收敛到统一信号契约 **`[datetime, vt_symbol, signal]` 三列 Polars DataFrame**。CNN 是一种信号生成器；规则策略只是一种**不需要训练的信号生成器**。下游的回测引擎、TopK 策略、任务轮询、图表渲染全部可复用。

### 1.3 必须先修的阻塞缺陷（进入 Phase 0）

1. **停牌日可成交**（F7）——对小市值策略是数量级级别的回测失真
2. **涨跌停 ±10% 硬编码**（F6）——创业板/科创板/北交所/ST 全部失真
3. **T+1 全局布尔**（F5）——转债 T+0 无法表达；`sell_to_close_intrabar` 绕过 T+1 顺带修复
4. **沪市转债代码归一化 bug**（F10）——做转债的前置，且是现网正确性 bug
5. **印花税默认值过时**（F9）

### 1.4 要继承的工程红线

- **Property 7**：决策/提醒链路与券商下单在 import 图上隔离
- **凭证脱敏**：通知凭证只从环境变量读取，计划/trace/日志零泄漏
- **幂等三层**：决策 signal_id / 调度 slot / 下单 client_order_id
- **数据两段式**：下载先入 imports 批次，校验后合并晋级
- **回测 ≡ 实盘同源**：同一信号函数同时服务回测与实盘（延续 label≡出场≡撮合红线的精神）
- **spec→属性测试**：关键不变量写成 Hypothesis/fast-check 属性

## 二、需求

### 2.2 需求清单

### 3.2 核心抽象：信号源注册表

**位置**：扩展 [registry.py](../backend/aitrade/backtest/registry.py)（协议已在此，加一张并行注册表），规则实现放新包 `backend/aitrade/rules/`。

```python
# backtest/registry.py 追加
SignalSourceFactory = Callable[[dict], SignalProvider]  # params -> provider
_SIGNAL_SOURCE_REGISTRY: dict[str, SignalSourceFactory] = {}

def register_signal_source(name: str, factory: SignalSourceFactory) -> None: ...
def build_signal_source(name: str, params: dict) -> SignalProvider: ...
def list_signal_sources() -> list[str]: ...
```

**设计决策**：
- 复用既有 `SignalProvider.predict(start, end, on_progress)` 协议（F3），不发明新接口
- 工厂接收 `params: dict`（标的池、窗口、过滤阈值），返回已绑定参数的 provider——回测与实盘用**同一工厂同一参数**构造，结构性保证一致（R2.3）
- CNN 适配器 `rules/cnn_adapter.py`：把 `predict_cnn_signals(model_name=...)` 包成 provider，注册为 `cnn`；orchestrator 的信号源参数化（F16）后，CNN 决策路径切换到经注册表取源，行为不变（现有测试守护）
- 新包 `rules/` 与 `cnn/` 平级（同为信号生产域），不塞进 alpha/（那是 ML 训练域）

### 3.3 三个内置信号源算法

**`etf_momentum`**（rules/etf_momentum.py）
- params: `universe: list[str]`（默认 510300/510500/159915/518880/511010 等）、`lookback=20`、`top_k=1`、`min_momentum=0.0`
- signal = R(lookback) 区间收益率；**绝对动量过滤**：momentum < min_momentum 的标的当日不出信号行 → 全体无信号时策略自然空仓（现金即防御）
- 数据：`lab.load_bar_frame(vt_symbol, "d", ...)` 逐标的取 close 计算，polars 向量化

**`cb_double_low`**（rules/cb_double_low.py）
- params: `top_k=15`、`max_price=130`、`min_rating="AA-"`、`exclude_announced_call=True`
- score = 转债收盘价 + 转股溢价率×100，升序取 top_k
- 过滤：评级 < min_rating、已公告强赎、剩余规模过小、上市 < 5 日
- 数据：转债日线（bars 复用）+ 历史溢价率与条款（rules/store.py 的 cb_terms parquet）

**`small_cap`**（rules/small_cap.py）
- params: `top_k=20`、`min_price=2.0`、`min_list_days=60`、`min_amount=3_000_000`、`exclude_st=True`
