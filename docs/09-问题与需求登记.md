# 问题与需求登记

> 用途：在日常使用系统过程中，随手登记遇到的问题（Bug）和想优化的点（需求/改进）。
> 用法：直接在下方表格新增一行即可，先记下来不用想太细，后续再整理分级。

---

## 使用说明

- **快速登记**：遇到问题先填「编号 / 日期 / 类型 / 模块 / 标题 / 描述」即可，其余字段可留空，事后补。
- **编号规则**：`类型缩写-序号`，如 `B-001`（Bug）、`F-001`（功能/需求）、`O-001`（优化）。
- **类型**：`Bug` 缺陷 / `需求` 新功能 / `优化` 体验或性能改进。
- **优先级**：`P0` 阻塞必须立刻处理 / `P1` 重要尽快 / `P2` 一般 / `P3` 有空再说。
- **状态**：`待处理` / `处理中` / `已完成` / `已搁置` / `已取消`。
- **模块**：如 `数据准备`、`数据回测`、`CNN`、`实盘交易`、`前端`、`后端`、`其他`。
