# AITrade 项目总览

> **版本**: 0.1.0 · **维护者**: Kevin · **更新日期**: 2026-06-04

## 一、项目定位

AITrade 是一个端到端的**智能量化交易研究平台**，面向量化研究者提供从数据采集、因子挖掘、模型训练、信号生成到策略回测的完整工作流。系统融合传统机器学习（LightGBM / Lasso）与深度学习（CNN / MLP），支持多品种、多周期的量化研究。

## 四、核心数据流

```
数据获取 → 本地存储 → 特征计算 → 模型训练 → 信号生成 → 策略回测
  │            │            │            │            │            │
  ▼            ▼            ▼            ▼            ▼            ▼
Tushare    Parquet     Alpha101/158  LGB/MLP/CNN  predict()   BacktestEngine
CSV导入    AITRADE_HOME/  自定义表达式   checkpoint   signal_df   Sharpe/DD/PnL
```

**完整研究流程**：

1. **数据准备** — 从 Tushare 下载行情或 CSV 导入，支持日线/分钟线/Tick
2. **周期聚合** — 从原始数据聚合出派生周期（如 1m → 5m/15m/30m）
3. **数据集创建** — 选择因子库 (Alpha101/Alpha158)，计算特征 + 标签
4. **模型训练** — Alpha 路线 (LGB/MLP/Lasso) 或 CNN 路线 (多尺度卷积)
5. **信号生成** — 用训练好的 Alpha 模型对新数据进行预测
6. **策略回测** — 基于信号运行回测，输出 Sharpe、最大回撤等指标

## 六、运行时数据存储

所有运行时数据存储在项目根目录下的 `./.aitrade/`：

```
${AITRADE_HOME}/
├── alpha_lab/                # Alpha 研究数据
│   ├── daily/               # 日线 Parquet 文件
│   ├── minute/              # 分钟线 Parquet
│   ├── ticks/               # Tick Parquet
│   ├── derived/             # 派生周期
│   ├── datasets/            # 数据集 pickle
│   ├── models/              # Alpha 模型 pickle
│   └── signals/             # 信号 Parquet
├── cnn_models/              # CNN 模型 checkpoint
│   ├── {name}.pt            # PyTorch 权重
│   └── {name}_history.json  # 训练历史
└── tasks.db                 # 任务状态（如启用持久化）
```

## 七、环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `TUSHARE_TOKEN` | _(必填)_ | Tushare API Token |
| `TUSHARE_BACKEND` | `tushare` | 数据后端 (`tushare` / `tinyshare`) |
| `AITRADE_HOST` | `0.0.0.0` | 后端监听地址 |
| `AITRADE_PORT` | `8000` | 后端监听端口 |
| `AITRADE_MAX_WORKERS` | `4` | 并行工作线程数 |
| `VITE_API_BASE_URL` | `http://localhost:8000` | 前端 API 地址 |
| `VITE_WS_URL` | `ws://localhost:8000` | 前端 WebSocket 地址 |

## 八、快速启动

```bash
# 后端
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e .
export TUSHARE_TOKEN=your_token
uvicorn aitrade.main:app --host 127.0.0.1 --port 8000 --reload

# 前端
cd frontend
npm install && npm run dev
```
